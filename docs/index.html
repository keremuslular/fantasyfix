Download for Mac

Safari setup

  1. Unzip the download and move FantasyFix to your Applications folder. Open it once.
  2. In Safari: Settings → Extensions, tick FantasyFix.
  3. Allow it on espn.com when Safari asks (or via Edit Websites…), then reload fantasy.espn.com.

What it does

In some regions ESPN's stats server (site.api.espn.com) answers the fantasy site with “Access Denied”, so parts of the matchup and roster pages never load. ESPN serves the same data at site.web.api.espn.com, which isn't blocked. FantasyFix sends those requests there instead. That's all it does: it collects no data, shows no ads and changes nothing else.

The ESPN mobile app can't be fixed by an extension; on phones, use fantasy.espn.com in a browser if you need it.

Support

Something not working? Open an issue on GitHub with your browser, country and which page is missing data.
